TeamPulse MCP server · status

Server: teampulse-mcp 1.0.0 · Tools: list_tasks (read-only) · Scope: read only, no write tools.

This page is the server's published status endpoint. The server itself is mcp-server/server.mjs in the repo and runs with no dependencies:

node mcp-server/server.mjs          # stdio transport for an MCP client
node mcp-server/server.mjs --http   # JSON-RPC over HTTP on :8787

Example call over stdio:

{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"list_tasks","arguments":{"column":"inprogress"}}}

Why only one tool, and why read-only, is in the autonomy justification.
