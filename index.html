TeamPulse Rebuild

The C2 task board, rebuilt the deliberate way: grounded handbook answers, a governed stale-task agent, and an audit log.

Board

Click a task's buttons to move it. Tasks that have sat in In progress for 7 or more days are marked stale (handbook §H3).

Ask the handbook

Grounded answers only: every reply quotes a handbook passage and cites it. If nothing in the handbook matches, it says so instead of guessing.

Try: When is a task stale? · How do I roll back a release? · What is the wifi password?

Stale sweep agent

Reads the board through the same list_tasks tool the MCP server exposes, finds stale tasks, and proposes moving them back to To do. Nothing moves until you approve (confirm-gated writes).

    Audit log

    Every agent step, approval, and rollback, newest run first. Stored in this browser. Exported runs from the build are in the repo.
